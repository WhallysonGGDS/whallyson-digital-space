# Digital Space

Aplicação web desenvolvida por **Whallyson Gabriel Garcia da Silva** com foco em organização de estudos, anotações e conteúdos digitais.

Projeto criado para **aprendizado prático** e **portfólio profissional**.

---

## 🎯 Objetivo

Centralizar anotações, ideias e conteúdos de estudo em um único lugar, com uma interface moderna, rápida e intuitiva.

---

## 🛠️ Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

---

## 🚀 Rodar localmente

Pré-requisitos:
- Node.js (LTS recomendado)
- npm

```bash
# instalar dependências
npm install

# subir ambiente dev
npm run dev
```

Acesse:
- http://localhost:5173

---

## 📦 Build

```bash
npm run build
npm run preview
```

---

## 🌐 Deploy

Compatível com Netlify/Vercel. Em geral:
- build: `npm run build`
- pasta de saída: `dist`
